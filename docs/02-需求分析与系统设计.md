# 二、需求分析与系统设计

## 需求分析
### 功能性需求
- 用户：注册/登录，管理员用户管理
- 数据管理：.h5ad 导入、校验、预处理、增删
- 索引：构建/保存/加载，多种索引结构
- 检索（核心）：按细胞编号或向量检索 Top-K，支持索引类型/度量/数量/条件设置
- 可视化：结果展示
- 评测：响应时间、召回率

### 非功能性需求
- 性能：大规模向量下低查询延迟
- 可扩展：可插拔索引算法
- 易用：Web 界面操作

## 系统设计
前后端分离架构：

```
[Vue3 前端] --HTTP/JSON--> [Flask API] --> [SearchService]
                                              ├── DataLoader (.h5ad)
                                              └── Index (Flat / FAISS: IVF/HNSW/PQ)
```

## 详细设计
- `BaseIndex`：统一索引接口 `build / search / save / load`。
- `create_index(type, dim, metric)`：索引工厂，便于扩展算法。
- `SearchService`：维护当前数据集与索引单例，提供检索与条件过滤。
- API 蓝图：`auth / datasets / index / search / eval`。
