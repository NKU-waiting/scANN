# 五、用户手册

## 启动系统
### 后端
```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python run.py            # http://127.0.0.1:5000
```
### 前端
```bash
cd frontend
npm install
npm run dev              # http://127.0.0.1:5173
```

## 使用流程
1. 打开前端页面，查看顶部「索引状态」确认数据集已就绪。
2. 输入 **查询细胞编号**，设置 **Top-K**、**索引类型**、**距离度量**。
3. （可选）填写 **限定细胞类型** 进行条件检索。
4. 点击 **检索**，下方表格展示 Top-K 相似细胞与查询耗时。

## 常见问题
- **FAISS 安装失败？** 系统会自动回退到内置 Flat（numpy）精确检索，功能不受影响。
- **检索结果为空？** 检查 cell_id 是否越界，或限定的细胞类型是否存在。
