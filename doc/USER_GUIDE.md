# scANN 用户手册

## 1. 登录与注册

打开前端后，未登录用户只能看到认证面板。新用户先注册再登录；开发演示也可使用 README 中说明的 demo 管理员。token 过期、用户被删除或服务端拒绝登录态时，页面会自动退出并返回登录界面。

管理员登录后会额外看到用户列表和删除操作。管理员不能删除自己。

## 2. 管理数据集

“数据集管理”始终列出可复现 demo 和已上传数据。

上传流程：

1. 选择 `.h5ad`、`.npy` 或 `.csv` 文件。
2. 填写数据集名称；留空时使用文件名。
3. `.h5ad` 默认使用 `X_pca`。填写 `X` 可强制读取表达矩阵，填写其他名称可选择相应 `obsm` 字段。
4. 点击“上传并激活”。系统校验成功后自动切换并建立 Flat/L2 基线索引。

切换数据集会清空当前页面的旧查询和评测展示，避免把旧结果误认为新数据结果。

只有管理员能删除数据集。活动数据集不能删除，应先切换到 demo 或其他数据集。删除数据集会同时清理其持久化索引。

## 3. 多数据集联合检索

上传至少两个数据集后，“多数据集联合检索”面板会自动选择首组维度相同的成员。使用前需要：

1. 勾选至少两个受管理数据集；
2. 填写可追踪的共享向量空间标识，例如 `atlas-pca-v1`；
3. 确认这些向量使用相同特征顺序或同一个 embedding 模型；
4. 选择索引与度量并构建联合索引；
5. 选择查询来源数据集和本地细胞编号，再执行跨数据集检索。

结果表逐行显示来源数据集、本地 ID 和细胞名称。系统会拒绝不同维度，但维度相同并不代表语义相同：不同数据集各自独立计算的 PCA 通常不在同一坐标基底中，不应直接联合。当前版本不自动执行特征对齐、批次校正或跨模型映射。

联合索引保存在当前后端进程内，删除任一成员数据集会使它失效；进程重启后需要重新构建。

## 4. 构建与持久化索引

查询表单支持：

- `Flat`：NumPy 精确基线；
- `FAISS-Flat`：FAISS 精确基线；
- `FAISS-IVF`：倒排聚类近似索引；
- `FAISS-HNSW`：图结构近似索引；
- `FAISS-PQ`：乘积量化索引。

度量支持平方 L2、Cosine 距离和内积。选择参数后点击“构建索引”。构建失败时旧索引仍可用。

“索引持久化”可保存当前索引。保存后可以构建其他索引，再从列表加载原索引。只有标记“兼容”的索引能在当前数据集加载；管理员可以删除非活动索引。

## 5. 执行查询

### 按细胞编号

选择“按细胞编号查询”，输入 `0` 到“细胞数 - 1”之间的整数。返回结果会自动排除查询细胞自身。

### 按向量

选择“按向量查询”，输入逗号分隔的有限数值。数值数量必须等于当前向量维度。页面会在请求前检查空片段、非数值和维度。

### 条件查询

“限定细胞类型”可填写 `cell_type` 值。条件查询保证所有返回项都符合该类型；若候选数少于 K，则只返回实际候选数。

### 索引对比

“对比索引”会使用同一份不可变查询参数，依次查询 Flat 和目标 ANN 索引，展示耗时、返回数和首位结果。

## 6. 理解结果

查询结果包括：

- 查询耗时、索引和返回数量；
- Top-K 结果表；
- 最佳/最差数值摘要；
- 距离或得分条形图；
- `cell_type` 分布；
- UMAP 或 PCA 二维散点图。

UMAP/PCA 图中红色为查询细胞、蓝色为 Top-K 结果、背景点按类型着色。点击任意散点，或聚焦后按 Enter/空格，会把该点作为新的细胞查询立即执行。向量查询没有独立查询细胞，因此只高亮结果。首次 UMAP 会触发 Numba 编译，后续会使用缓存。

平方 L2 和 Cosine 距离越小越相似；内积越大越相似。页面会随度量切换标题，避免把内积误写成距离。

## 7. 性能评测

在“性能评测”选择一个或多个索引，设置 K、查询样本数和度量。系统以 Flat 为 ground truth，展示：

- Recall@K；
- 平均单查询耗时；
- 索引构建耗时。

评测用于课程演示和相对比较，不应替代严格科研 benchmark。若需要比较参数，应保持数据集、度量、K、查询样本数和运行环境一致。

## 8. 运行历史

“运行历史”包含查询和评测两个页签。普通用户只看到自己的记录，管理员看到全局记录。为减少敏感数据和存储开销，向量查询只记录“向量查询”类型，不保存原始向量。

## 9. 常见问题

### 后端不可达

确认后端在 5000 端口启动、前端通过 Vite 开发服务器访问，并检查 CORS 配置。

### token 失效

页面会自动退出。重新登录即可；若用户已被管理员删除，需要重新注册或联系管理员。

### `.h5ad` 无法加载

检查目标 `obsm` 字段是否存在，或将字段设为 `X`。同时确认矩阵为二维、非空且不含 NaN/Inf。

### 索引不能加载

确认当前数据集与索引记录的数据集一致。文件或数据被外部修改后指纹会变化，系统会拒绝加载，应重新上传数据或重建索引。

### 无条件结果或结果少于 K

检查 `cell_type` 拼写。满足条件的细胞少于 K 时，返回数量会小于 K，这是保证型条件检索的预期行为。

### 联合索引提示维度或共享空间问题

维度不一致时应重新生成可比 embedding。维度一致时仍需确认所有成员使用同一特征顺序或同一模型；不要仅因都是 `X_pca` 就确认共享空间。成员被删除或服务重启后，请重新构建联合索引。
