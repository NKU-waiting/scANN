# 数据目录

本目录只保留说明文件和 `.gitkeep`。上传数据、真实 `.h5ad`、`.npy`、`.csv`、数据库和生成索引均不会进入 Git。

系统支持以下输入：

- `.h5ad`：优先读取 `obsm[X_pca]`；界面中将向量字段设为 `X` 可改读表达矩阵。
- `.npy`：二维、有限数值的“细胞 × 特征”矩阵；禁止 pickle 对象数组。
- `.csv`：可为纯数值矩阵；也可用 `cell_id` 指定唯一细胞名，用 `obs:<字段名>` 声明元数据列，其余列必须为数值特征。

真实数据提交前必须确认来源、许可和脱敏要求。仓库不附带任何私有或受限数据集。
